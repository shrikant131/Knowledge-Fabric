# Knowledge Fabric — Start Here

## Fastest path

```bash
./start.sh
```

Open `http://localhost:5050`. The application bootstraps the included sample knowledge and presents the browser Playground.

### Three ways to start

**Sample data** — zero credentials and zero configuration.

**Browser upload** — use Quick Start to upload supported files.

**Public GitHub** — enter `owner/repository` in Quick Start.

## Product surfaces

| Surface | Purpose |
|---|---|
| `/playground` | Ask questions and inspect evidence |
| `/quick-start` | Zero-configuration onboarding |
| `/admin` | Detailed control plane |
| CLI | Developer and CI automation |

## LLM

Local mode is always available. Enable Bedrock or OpenAI from Admin → AI & Models after configuring credentials.
