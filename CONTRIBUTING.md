# Contributing

## Development

1. Create a Python virtual environment.
2. Install the project dependencies using the documented installer.
3. Run syntax/tests available in the environment.
4. Keep secrets out of source control.
5. Update documentation when changing product behavior.

## Pull requests

Please include:

- What changed
- Why it changed
- How it was tested
- Any configuration or migration requirements

## Security

Never commit:

- AWS credentials
- API keys
- `.env` files
- private certificates
- production database files
- local indexes containing sensitive data
